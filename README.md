# Executive Sales Dashboard – Power BI

This project focuses on Data Analytics & Business Intelligence using Power BI.

## Features

* Data Modeling with Calendar Table
* DAX Measures
* KPI Cards
* Sales Trend Analysis
* Profit Analysis
* Region-wise Performance
* Interactive Slicers
* Executive-Level Dashboard

## Tools Used

* Power BI
* DAX
* Excel Dataset

## Key Insights

* East region generated highest sales.
* Consumer segment contributed maximum revenue.
* Sales peaked during June and September.
* Technology category showed strong profitability.
